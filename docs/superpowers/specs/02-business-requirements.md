## 1. 业务背景

### 1.1 客户与场景

| 项 | 内容 |
|---|---|
| 客户 | 国家统计局体系内（机器授权 `国家统计局专用版`，具体行政层级以正式合同为准） |
| 业务主线 | 1) 农业畜牧调查　2) 居民收支调查 |
| 使用者 | 调查员 / 辅调员（一线入户）、数据审核员、数据分析师 / 撰写员 |
| 部署 | 客户内网 / 信创环境 |
| 项目意义 | **标杆案例**，验证产品后将向全国统计系统推广（来自客户会议纪要 M6） |

### 1.2 核心痛点

1. 千万级账页/问卷数据读取审核效率低
2. 政策与编码规则庞杂，调查员现场难记忆，需即时问答
3. 凭证（用水电饲料发票）与上报数据匹配性低，人工对账成本高
4. 异常审核依赖经验，难以沉淀和复用

### 1.3 产品价值定位（客户视角）

> 客户内网部署的、以**数据分析为核心**的统计调查智能助手（来自客户会议纪要 M1）。

## 3. 业务场景需求

> **写法说明**：每条只描述业务，不写技术实现。优先级 P1（一期 MVP）/ P2（二期增强）。

### F. 数据接入场景

#### F1. 统计云数据自动获取 — P1
**业务描述**：自动从客户已有的"统计云"系统按月度/季度获取问卷数据与日记账数据。
**业务输入**：cron 调度触发；用户手动触发；事件触发（统计云有新数据时）
**业务输出**：原始数据落入本地存储；获取记录入审计；异常时通知管理员
**验收**：
- 配置后无需人工干预即可定期取数
- 错误自动重试 ≥ 3 次
- 获取记录可追溯（谁、何时、取了什么）
**来源**：S2 §二.7 + 选型澄清 C4

#### F2. 公网/内网网页数据抓取 — P1
**业务描述**：抓取**公网政策/数据**（农业农村部、河南省农业农村厅、发改委、省政府等）和**内网政策系统**数据形成本地知识素材。
**业务输入**：目标网站列表（待客户提供，见 §6 Q2）+ 抓取规则配置
**业务输出**：结构化的网页内容（标题/正文/发布日期/分类）入库
**业务约束**：
- 公网部分有**反爬机制**（M4），需多种技术路线兜底
- 内网抓取已经验证可行（M5）
**验收**：
- 给定 URL 列表后可批量抓取并入库
- 反爬被拒能切换策略并报警
- 抓取频次可配（联动 F1）
**来源**：S1 第 7 行 + S2 §二.2 + M4 + M5

#### F3. 凭证 OCR 识别与对账 — P1
**业务描述**：识别养殖场提交的**用水/用电/饲料购进凭证**照片，提取关键字段（金额/日期/单位/物品），与养殖场上报的数据自动对账。
**业务输入**：凭证照片（单张或批量）+ 对应上报数据
**业务输出**：结构化凭证字段 + 对账差异清单 + 人工复核 UI
**验收**：
- OCR 字段提取准确率 ≥ 90%（基于客户提供样本测试）
- 差异清单按养殖场分组
- 人工复核界面可批量处理
**来源**：S1 第 11 行

### G. 数据分析场景（核心 — M1）

#### G1. 大规模账页数据高效存取 — P1
**业务描述**：处理居民收支日记账（**3000 万条/年，约 5GB**）+ 9 张问卷表（合计 ~150MB/年）+ 畜牧业季报数据（~1 万条/季度）。
**业务输入**：从 F1/F2/F3 流入的原始数据
**业务输出**：可被快速查询的本地结构化数据
**性能要求**：
- 月度账页（~250 万条）分析端到端 ≤ 10 分钟
- 历年数据查询响应 ≤ 5s
**验收**：实测达标 + 内存占用与客户服务器配置相容（§6 Q4 待确认）
**来源**：S1 第 10 行 + S2 §一

#### G2. 多维数据汇总与标准化报表 — P1
**业务描述**：
- 按区域 / 行业 / 记账时间等维度**自定义汇总**
- 生成**分户表**数据
- 批量生成**市县/各指标汇总报表**
- 根据用户需求自动生成**统计年鉴**等标准化表格
- 调用特定指标历年数据
**业务输入**：维度选择 + 时间窗 + 指标 + 模板
**业务输出**：汇总表（Excel / CSV / Word）+ 标准化报表
**验收**：
- 用户可在 UI 配置维度
- 汇总规则可保存为模板复用
- 历年查询 ≤ 5s
**来源**：S2 §二.1 + §二.4

#### G3. 多类型图表自动生成 — P1
**业务描述**：按指标 + 时间序列自动生成柱状/折线/饼/热力/散点图；多图组合输出仪表板。
**业务输入**：指标 + 时间范围 + 图表类型
**业务输出**：可视化图表（PNG/SVG/Word 嵌入）+ 仪表板
**验收**：5 种图表全支持；可导出；可嵌入报告
**来源**：S2 §二.4 末段

### H. 数据核验场景

#### H1. 业务规则审核 — P1
**业务描述**：可配置的规则引擎，覆盖：
- 分户表 / 连续记账数据逻辑审核
- 凭证-上报数据对账（基于 F3 输出）
- **商品单价区间核验**（与外网抓取的价格区间库比对）
**业务输入**：数据集 + 规则库
**业务输出**：异常清单（带证据） + 可下钻原因
**验收**：
- 规则可配置（YAML/JSON 或 UI）
- 批量运行支持
- 新规则可热加载
**来源**：S2 §二.2

#### H2. 个人台账与异常识别 — P1
**业务描述**：基于记账户**历史工资 / 养老金发放数据**：
- 建立个人收入台账
- 自学习每人的发放时间 / 金额区间 / 发放频率特征
- 自动识别发放异常（时间 / 金额 / 频率偏离基线）
- 生成提示清单
**业务输入**：≥12 个月历史发放数据
**业务输出**：异常清单（按用户/类型分组）+ 误报/漏报阈值可调
**验收**：基线建立后异常识别准确率 ≥ 80%
**来源**：S2 §二.2

#### H3. 外部部门交叉验证 — P1
**业务描述**：对接**社保 / 医保 / 惠农惠民部门**数据进行交叉验证，识别漏记 / 多记 / 错记；按补贴类型、城乡生成漏记核查清单。
**业务输入**：客户本地数据 + 外部部门数据（接口方式 §6 Q5 待确认）
**业务输出**：交叉对账差异清单 + 漏记核查清单（按补贴类型）
**验收**：至少对接 1-2 个外部部门通道；结果可下钻；验证日志可审计
**来源**：S2 §二.2

#### H4. 异常规则自学习 — P2
**业务描述**：从历史审核数据持续学习异常模式；自动发现人工难以识别的异常；新型异常 → 规则草案 → **人工确认** → 规则库入库 → 热加载。
**业务输入**：历史审核结果 + 新数据
**业务输出**：规则草案 + 人工确认后的新规则
**验收**：
- 规则库版本化、可回滚、可审计
- 新规则不依赖重启生效
**来源**：S2 §二.6

### I. 数据评估场景

#### I1. 多维度数据评估 — P1
**业务描述**：三类评估合一：
1. **记账质量评估**：漏记率、错记率、连续未记账天数、未编码条数 → 户/县区得分 → 评估报告
2. **数据可信度评估**：一致性、逻辑性、完整性 → 标记低可信数据 → 提示重点核查
3. **结构匹配分析**：地区人口结构、收入结构、大户占比、高低户/五等分户收支合理性
**业务输入**：审核后的数据集
**业务输出**：分层评估报告（户/县/市）+ 低可信项清单 + 结构匹配报告
**验收**：
- 指标可配
- 报告按层级汇总可下钻
- 支持地图/图表可视化（联动 G3）
**来源**：S2 §二.3

### J. 智能撰写场景

#### J1. 实时监测与异常分析报告 — P1
**业务描述**：对收支记账数据、汇总数据实时监测异常趋势；结合外部政策/环境因素自动分析原因；生成异常分析报告。
**业务输入**：实时数据流 + 历史基线 + 政策知识库
**业务输出**：异常报告（含现象 + 可能原因 + 关联政策）
**验收**：
- 检测频率可配（cron 触发）
- 历史报告可对比
- 输出 Word/PDF/Markdown 可二次编辑
**来源**：S2 §二.8 前段

#### J2. 专项分析报告自动撰写 — P1
**业务描述**：自动开展常用专项分析并生成报告**初稿**：
- **居民收入结构分析**
- **消费结构分析**
- **惠民惠农补贴分析**
**业务输入**：分析时间范围 + 专项类型 + 数据集
**业务输出**：报告初稿（Word/PDF/Markdown）
**验收**：
- 至少 3 种专项模板
- 初稿包含数据 + 图表 + 文字结论
- 可二次编辑
**来源**：S2 §二.8 末段

### K. 知识问答场景

#### K1. 调查员现场智能问答 — P1
**业务描述**：调查员/辅调员通过**文字或语音**提问，系统基于本地知识库（住户调查制度、惠民惠农补贴政策、收支编码规则、记账规范）给出准确答案。**针对入户场景**提供标准化解答话术（应对记账户不配合、补贴政策解释等常见问题）。
**业务输入**：自然语言问题（文字/语音）+ 场景上下文（入户/办公室）
**业务输出**：答案 + 知识来源引用 + 标准化话术（如场景适用）
**验收**：
- 文字问答延迟 ≤ 3s
- 语音输入支持（ARM 兼容性 §6 Q3）
- 答案附带知识来源引用
- 标准话术覆盖典型场景
**来源**：S1 第 8-9 行 + S2 §二.5

## 5. 客户业务工作流（业务流程视图）

### 5.1 月度居民收支审核流程

```
每月初触发
  ↓
取数（F1 统计云 + F2 网页抓取最新政策）
  ↓
入库与汇总（G1 + G2）
  ↓
并行核验（H1 业务规则 + H2 个人台账 + H3 外部交叉）
  ↓
异常命中 → 政策查询（K1 知识库）
  ↓
评估（I1 多维评估）
  ↓
报告生成（J1 异常分析 + J2 月度报告）
  ↓
推送给审核人员 + 高优异常告警
```

### 5.2 调查员现场问答流程

```
调查员现场遇到问题
  ↓
笔记本/手机访问平台
  ↓
文字或语音提问（K1）
  ↓
答案 + 引用 → 调查员据此处理
```

### 5.3 业务人员自助 Skill 创建流程（M2 差异化）

```
业务人员："我想要一个 X 功能"
  ↓
Skill Meta-Agent 多轮澄清提问
  ↓
生成 Skill 草案（含 Python 脚本，降低 LLM 幻觉）
  ↓
预览确认 → 写入工坊（沙箱执行）
  ↓
即可被其他业务功能调用 → 自我测试
```
